## 1. 项目背景

- `LittleFish` 已经完成，后续只作为 SeaS 内置摸鱼阅读模式使用。
- `SeaS` 是当前主要开发项目，定位为完全本地的 TXT 阅读器。
- 用户可能同时安装单独版 LittleFish 和 SeaS；当用户在 SeaS 中使用摸鱼模式阅读时，必须调用 SeaS 内置的 LittleFish，而不是系统里单独安装的 LittleFish。
- 当前优先级：先完成普通阅读模式和主页面管理能力，LittleFish 集成细节后置。

---

## 2. 已确认的产品方向

### 2.1 基础定位

- SeaS 是完全本地阅读器。
- 不做账号、云同步、云备份。
- 不做开机自启。
- 异常日志只用于开发阶段。
- 版本号目前使用 `1.0` 即可。

### 2.2 窗口与退出逻辑

- 软件关闭时默认隐藏到系统托盘。
- 用户想退出进程，需要在托盘图标右键选择退出。
- 普通窗口尺寸、位置、阅读设置、默认阅读模式等需要记忆。

### 2.3 文件处理

- TXT 文件移动后，需要提醒用户，并让用户手动重新定位。
- 不应直接删除用户本地 TXT 文件。
- “从书架移除”只删除 SeaS 的书架记录，不删除原文件。
- 右键“使用 SeaS 打开”的系统菜单集成暂时后置，不一定会做。

### 2.4 阅读与统计

- 阅读进度需要保存。
- “正在读”与“最近打开/最近阅读”重复，因此不需要单独做。
- 阅读统计不做，避免累赘。
- 每个文件需要记录上次打开日期。
- 已读标记不做。

### 2.5 书架与分类

- 标签系统不做。
- 收藏与分组作为书籍整理能力的一部分。
- 支持用户自定义分组。
- 支持新建、删除、重命名、排序分组。
- 分组不展开固定放在侧边栏，避免分组过多时挤爆导航。

## 3. 当前 UI / 交互决策

### 3.1 顶部主分类

主页面顶部分类最终确定为：

```text
全部书籍 / 我的分组 / 我的收藏 / 搜索框 / 窗口按钮
```

说明：

- 原“我的书架”改为“全部书籍”。
- 原“分组显示”后来改为“我的分组”。
- “我的收藏”和“我的分组”的顺序曾调整，当前是“我的分组”在前，“我的收藏”在后。
- 顶部分类风格参考轻量 tab，不做明显边框方块。
- 选中状态使用主题蓝色文字和下划线。

### 3.2 我的分组页

- 添加分组和分组排序放在“我的分组”页面内容区，不放在顶部栏。
- 分组标题行需要视觉轻、干净。
- 分组支持展开/收起，默认展开。
- 分组名后带编辑图标，可直接重命名。
- 重命名时：
  - 回车确认。
  - 点击空白处也确认。
  - 空名称或重复名称会回退并提示。
- “未分组”不可重命名。
- 分组排序通过弹窗完成。
- 分组排序弹窗里支持拖动排序、重命名、删除。

### 3.3 书籍卡片

- 主页面书籍卡片已经缩小。
- 去掉书籍阴影。
- 书籍卡片与“全部书籍”等标题区域左侧对齐。
- 书籍右键菜单保留：
  - 正式阅读
  - 用 LittleFish 打开
  - 收藏 / 取消收藏
  - 移动到分组
  - 编辑书籍信息
  - 定位原文件
  - 从书架移除

### 3.4 最近阅读

- 主页面不再固定显示“最近阅读”区域。
- 点击左侧导航栏“最近阅读”时，主界面只显示用户打开过的书籍。
- 最近阅读最多显示 10 本，按打开顺序排序。

## 4. 普通阅读模式记录

### 4.1 已处理的问题

- 阅读进度保存与恢复。
- 正在读功能与最近打开重复，已移除或不再单独作为核心功能。
- 横向翻页显示问题和随便翻几页闪退的问题被列为优先级，并已做过修复。
- 阅读正文出现白色底色的问题已修。
- 阅读设置窗口滚轮事件已优化：
  - 鼠标放在设置窗口里滚动时，不应继续滚动正文。
- 搜索结果列表已做。
- 书签支持自定义命名。
- 普通阅读模式自动翻页已做：
  - 开关放在导航栏。
  - 自动翻页速度设置放在阅读设置中。

### 4.2 专注模式

原“沉浸模式”后来改名为“专注模式”。

确认交互：

- 不开启专注模式时：
  - UI 与导航栏常驻显示。
  - 调整页边距时正文不能被 UI 压住。
- 开启专注模式时：
  - UI 和导航栏默认隐藏。
  - 鼠标移动到左侧触发区域时，只呼出左侧导航栏。
  - 鼠标离开后导航栏自动收起。
  - 呼出导航栏时不显示其它 UI。
  - 呼出导航栏时不重新排版正文。
  - 专注模式开关放在阅读导航栏里，不放在阅读设置中。

已做过的细节调整：

- 专注模式按钮文案：
  - 未开启时显示“专注模式”。
  - 开启后显示“退出专注”。
- 左侧触发区域扩宽到 `50px`。
- 导航栏收起等待时间从 `30ms` 调整到 `10ms`。
- 专注模式下左侧导航栏增加关闭窗口按钮：
  - 作用是关闭窗口并收回系统托盘。
  - 不退出进程。
  - 不改变专注模式开关。
- 关闭窗口图标按用户参考图替换过。

### 4.3 章节标记样式

- 章节标记底色保持原绿色。
- 曾重点调整章节名垂直居中问题。
- 章节标记字体改为宋体。
- 章节标记不要加粗。
- 需要注意数字 `0` 和 `1` 在部分字体下观感不一致的问题。

## 5. 主页面已实现功能

### 5.1 自定义分组

已实现：

- 新建分组。
- 分组重命名。
- 分组删除。
- 分组排序。
- 书籍移动到分组。
- 书籍设为未分组。
- 我的分组页按分组展示书籍。
- 每个分组可展开/收起。
- 未分组显示在分组列表底部。
- 分组为空时也可显示，方便管理。

相关数据：

- `BookGroup`
  - `Id`
  - `Name`
  - `SortOrder`
  - `CreatedAt`
- `BookItem`
  - `GroupId`
  - `FavoritedAt`
- `LibraryState`
  - `Groups`

### 5.2 收藏

已实现：

- 书籍可收藏 / 取消收藏。
- 收藏记录有 `FavoritedAt`。
- 旧收藏数据会补齐收藏时间。
- “我的收藏”按收藏顺序显示。

### 5.3 批量操作

已实现于“全部书籍”页面内容区，不放顶部栏。

进入批量操作后：

- 书籍卡片出现勾选圆点。
- 点击书籍只选中 / 取消选中，不打开阅读。
- 显示“已选 X 本”。
- 支持全选当前结果。
- 支持取消选择。
- 支持退出批量。

批量操作支持：

- 加入收藏。
- 取消收藏。
- 移动到分组。
- 设为未分组。
- 从书架移除。

说明：

- 批量“从书架移除”只删除 SeaS 记录，不删除原 TXT 文件。
- 搜索状态下，“全选当前结果”只选中当前搜索结果，不选中全书架。
- 批量选择状态只在运行时临时存在，不保存进 `library.json`。

### 5.4 排序

已实现于“全部书籍”页面内容区。

排序项：

- 最近阅读。
- 最近添加。
- 书名。
- 作者。
- 阅读进度。

排序方向：

- 升序。
- 降序。

说明：

- 不做“上次打开时间”这个单独排序项。
- 排序偏好会保存到本地状态。
- 排序只影响“全部书籍”。
- “我的收藏”和“最近阅读”保持各自原本排序逻辑。

### 5.5 失效书籍检测

已实现：

- “全部书籍”页面内容区提供“检测失效书籍”。
- 检测书架中原 TXT 路径不存在的书。
- 如果没有失效书籍，提示没有发现。
- 如果发现失效书籍，弹出窗口。
- 弹窗中默认全选失效项，用户可取消选择。
- 确认后只从 SeaS 书架移除记录，不删除本地 TXT 文件。

## 6. 最近修复的小问题

### 6.1 最大化窗口顶部栏单击问题

问题：

- 窗口最大化时，单击顶部栏会还原成小窗口。

期望：

- 单击不改变窗口大小。
- 双击顶部栏才切换最大化 / 还原。

处理：

- 修改顶部栏拖动逻辑。
- 最大化状态下不再因为单击拖动而还原窗口。

### 6.2 搜索框光标与占位文字重叠

问题：

- 输入光标在搜索框里时，会压在“搜索...”文字下面。

处理：

- 搜索框获得焦点时隐藏占位文字。
- 失去焦点且内容为空时再显示占位文字。

### 6.3 分组显示后面的加号

问题：

- “分组显示 / 我的分组”后面的 hover 加号与页面内“添加分组”功能重复。

处理：

- 移除顶部 tab 后的加号按钮。
- 移除对应点击逻辑。

### 6.4 顶部 tab 文案与顺序

处理：

- “分组显示”改为“我的分组”。
- 顶部顺序为：

```text
全部书籍 / 我的分组 / 我的收藏
```

## 10. 工作习惯记录

- 用户希望先讨论清楚方案，再集中实现，避免一个按钮一个按钮反复改。
- UI 需要注意视觉表现，不要过度方块化、边框化。
- 功能入口不要堆到顶部栏，主页面功能应放在主内容区。
- 小修改无需默认重启软件。
- 如果需要重启，应先说明原因。
