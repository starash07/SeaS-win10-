# SeaS

SeaS 是一个面向本地 TXT 书籍的 Windows 桌面书架和阅读器，使用 C#、WPF 与 .NET 8 开发。当前目标版本为 1.0.1。

## 产品原则

- 完全本地运行，只读取本地 TXT 文件，不提供云同步、用户账号或数据备份功能。
- 普通阅读模式是当前开发重点；LittleFish 作为 SeaS 内置的摸鱼阅读器后置完善。
- 关闭主窗口时默认隐藏到托盘，用户通过托盘菜单手动退出。
- 默认阅读模式、阅读设置、窗口尺寸和窗口位置都要记忆。
- Release 版本不记录异常日志；诊断日志只在开发构建中使用。
- 不做开机自启、标签、已读标记和阅读统计。

## 当前状态

已经实现：

- TXT 文件导入、拖放导入和文件夹递归扫描。
- 书架搜索、最近阅读和收藏筛选。
- 书名与作者编辑、原文件定位、从书架移除。
- 单实例启动、系统托盘和窗口状态处理。
- 内嵌 TXT 阅读器，以及调用 LittleFish 阅读。
- 章节识别、章节跳转、书签和书内搜索。
- 滚动/翻页阅读、阅读进度、字号、行距、正文宽度、字体和主题设置。
- 每本书的阅读章节与章节内进度保存和恢复。
- 摸鱼模式固定调用 SeaS 随附的 LittleFish，不受系统中单独安装版本影响。
- 书内搜索结果列表，显示章节位置与上下文摘要并支持点击跳转。
- 书签自定义名称和重命名。
- 自动翻页，默认间隔 5 秒，可在 1～3600 秒范围调整。
- 主窗口尺寸、位置和最大化状态记忆。
- 可持久化的沉浸模式：通过导航栏按钮直接开关；开启后隐藏全部阅读 UI，鼠标进入最左侧热区时仅以覆盖层临时显示导航栏，离开后恢复隐藏，不显示上下栏、不退出沉浸模式，也不触发正文重排；导航栏提供独立的“关闭到托盘”入口。
- 普通模式始终显示导航和 UI，并为可见导航栏保留正文安全边距。
- Debug 构建专用异常日志；Release 构建不写诊断日志。
- 书架、书签及阅读偏好保存到 `%LOCALAPPDATA%\SeaS\library.json`。

- 显示每本文件的上次打开日期。
- TXT 文件移动或丢失时提醒用户，并允许用户手动定位新文件，同时保留阅读进度、书签、收藏和分组。

## 项目结构

- `SeaS.sln`：Visual Studio 解决方案。
- `src/SeaS.App`：WPF 主程序。
- `src/SeaS.App/EmbeddedReaderControl.*`：内嵌阅读器界面与逻辑。
- `src/SeaS.App/Models`：书籍、章节、书签和阅读偏好模型。
- `src/SeaS.App/Services`：书架持久化、元数据和 TXT 解析。
- `src/SeaS.App/Plugins/LittleFish`：随 SeaS 分发的 LittleFish 运行文件，不是构建垃圾。
- `design`：书架、阅读器和整体界面原型。
- `scripts/check-environment.ps1`：开发环境检查。

## 开发环境

- Windows 10/11
- .NET 8 SDK
- Git
- Visual Studio 2022、Rider 或 VS Code（可选）

仓库通过 `global.json` 固定使用 .NET SDK 8.0.422，并允许自动选择同一功能带内更新的补丁版本。

检查环境：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check-environment.ps1
```

还原和构建：

```powershell
dotnet restore .\SeaS.sln
dotnet build .\SeaS.sln -c Debug --no-restore
```

运行：

```powershell
dotnet run --project .\src\SeaS.App\SeaS.App.csproj
```
